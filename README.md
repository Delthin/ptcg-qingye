# 一起打牌 · PTCG 简中

面向简体中文卡池的非官方 PTCG 收藏、组牌与双人对战应用。包含 React 前端、Node.js 规则服务、SQLite 存档，以及恢复当前素材快照的下载脚本。

可以注册独立账号、签到领取游戏元、购买与拆开卡包/预组、整理收藏、编辑卡组，再邀请另一位玩家对战。游戏元是站内虚拟数值，不接入真实支付。

当前按**本地功能预览版**发布，继承的依赖仍有高危和严重安全告警。默认仅监听本机；长期开放到公网前需先升级和审查依赖，详见 [安全状态](SECURITY.md)。

## 目前实现到哪里

这是当前可玩版本的快照，已包含**三十周年庆典与嗨皮 H1–H6**，并非所有简中卡牌都已实现对战效果。

| 内容 | 当前状态 |
| --- | --- |
| 简中卡牌资料 | 11,847 条印刷记录，包含卡名、编号、稀有度、卡图与规则引擎映射 |

| 嗨皮组合 H1–H6 | 6 个系列、24 套 60 张预组；支持随机单套与四套整盒，整盒附包按当前配方发放 |
| 三十周年硬币 | 蓝色、金色共 60 枚，包含收藏、选用与对战掷硬币表现 |

收藏页会标记暂不能用于对战的卡。卡组采用 60 张、同名最多 4 张（基本能量除外）等构筑规则，服务端再次验证。房间以自由对战为主，不强制按 G/H/I/J 轮换过滤。

“已映射”表示引擎存在对应卡牌实现，不等于每张卡的全部效果都完成了逐卡验收。具体缺口见 [内容状态](CONTENT_STATUS.md)。

本版已在 macOS、Node.js 22.23.4、Python 3.14.3 上完成安装构建、新账号注册与预组发放、签到、三十周年开包、嗨皮 H6 预组拆封及双账号进入牌桌的验证；牌桌已实测显示简中卡图和桌布。

## 下载后运行

支持 macOS、Linux；Windows 请使用 WSL2。准备：

- Node.js **22.12+（推荐 22 LTS）或 24 LTS**；仓库 `.nvmrc` 固定当前验证版本。
- Python **3.10+**，需要可用的 `venv` 和 `pip`。
- 至少约 **16 GB** 可用空间，能访问 GitHub Raw、宝可梦中国官网和 PokéWalls，以及配置的 npm、Python 包源（通常为 npm registry、PyPI 和其文件下载域名）。首次核心素材下载约 **3.70 GB**。
- `sqlite3` 无可用预编译包时，需要系统 C/C++ 构建工具。

在此仓库点击 **Code → Download ZIP** 并解压，或用 Git 克隆，然后进入项目根目录：

```bash
# 使用 nvm 时，先运行 nvm install && nvm use
npm run setup
npm start
```

打开 **http://localhost:8080**。

`setup` 会创建仅保存在本机的随机签名密钥和注册口令，下载并校验卡图、界面图片与音效，在项目自己的 `.venv` 安装图像处理依赖，再安装并构建前后端。完成的素材会复用，下载中断后可以重跑。服务只在运行 `npm start` 后启动。

查看本机的注册口令：

```bash
npm run room:invite
```

在注册页使用该口令创建账号。新账号会随机获得一套嗨皮预组和一套对战派对预组，卡组和对应持有卡牌一起入账；进入牌桌后即可使用。另一个玩家在同一实例注册后，可以互相发起邀请。

每次全新安装都有自己的数据库；已有账号、余额、收藏和对局记录不会随源码分发。

### 恢复背景音乐

背景音乐需要额外安装 `ffmpeg`，并由使用者确认外部音源的使用条件。先查看清单，再决定是否下载：

```bash
npm run assets:music -- --list
npm run assets:music -- --accept-source-terms
npm run assets:music:check
npm run build
```

音乐在前端构建时打包，因此下载后必须运行 `npm run build`；服务已运行时，再停止并重新执行 `npm start`。清单固定当前 39 段曲目及其裁切方式。BGM 只影响背景音乐；缺少它时卡图、音效和对战仍可使用。源站限流或下架时，脚本会列出缺失曲目和手工准备入口，不会改变前端播放清单。

## 常用操作

```bash
npm run assets:check       # 离线校验完整核心素材，不重新下载
npm run assets:prepare     # 补下载缺失核心素材
npm run build              # 修改源码后重建
npm run dev                # 开发前端；后端另用 npm start 启动
npm run check:downloads    # 素材下载器的离线测试
```

下载器不会覆盖内容不同的已有文件。出现冲突时，先检查报告 `.cache/assets-report.json`，自行备份并移走冲突文件后重试。首次安装、源站连接和 SQLite 构建问题见 [部署说明](DEPLOYMENT.md)。全部脚本入口见 [脚本说明](SCRIPTS.md)。

## 源码、素材与存档

仓库提交源码、依赖锁文件、可运行的数据快照、配方、素材下载清单及授权字体。卡图、音频等大体积素材从原来源下载；`.env`、SQLite 数据库、下载缓存、依赖与编译产物均不提交。

这是固定内容快照。当前工具恢复这版数据和素材；未来卡池更新仍需维护映射、规则实现与配方，不会自动抓取新卡。来源和版本见 [DATA_SOURCES.md](DATA_SOURCES.md)。
